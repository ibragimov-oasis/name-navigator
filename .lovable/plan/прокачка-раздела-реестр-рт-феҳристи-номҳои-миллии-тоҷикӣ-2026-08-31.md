# Прокачка раздела «Реестр РТ» (Феҳристи номҳои миллии тоҷикӣ)

Ничего не удаляем: все текущие вкладки, диалоги, TTS-плеер и данные остаются. Только чиним, ускоряем и дописываем.

## 1. Текущее состояние (проверено по коду)

Что есть:
- `src/pages/TajikNames.tsx` (1191 строка) — одна большая страница с вкладками: Каталог, Санҷиш (проверка имени), Генератор, Инфографика, Қонунгузорӣ.
- Данные: `src/data/tajikRegistryData.json` — **3 461 имя** (2 007 мужских, 1 454 женских), поле `legal_decree` = Қарори №98 от 26.02.2026.
- Логика: `src/data/tajikRegistry.ts` — алфавит, нормализация, `checkTajikNameLegality`, статистика по буквам. Типы в `tajikTypes.ts` (строгие, `any` в разделе нет).
- Компоненты: детальный диалог, справка-выписка, генератор, TTS-плеер + настройки, хук `useTajikAudioReader`.
- Тесты: `src/test/tajikRegistry.test.ts` (количества, проверка имени, статистика).
- Маршруты `/tajik-names` и `/tajikistan`, ссылки из Header, MobileBottomNav, Index.

Чего не хватает:
- Из 3 461 имени только **1 267 имеют значение/историю** (2 194 — пустые `meaning`/`history`), и лишь 250 связаны с основным каталогом (`matched_child_name_id`). В Supabase (`names_enriched`) таджикских записей **нет вообще** — раздел полностью статичный.
- Нет SEO-блока (title/description/JSON-LD) — при том что это самый посещаемый и уникальный раздел.
- Нет состояния в URL: фильтр/буква/страница/имя нельзя расшарить, нет ссылки вида `/tajik-names?name=Абирафшон`.
- Нет скелетонов, пустых состояний и обработки ошибок; нет офиц. ссылки на источник (Кумитаи забон).

## 2. Баги и производительность

- **3.3 МБ JSON импортируется синхронно** в главный бандл (`App.tsx` грузит страницу без `lazy`) — это главная причина «тормозов»/белого экрана на мобильном. Чиним: `React.lazy` для маршрута + асинхронная загрузка данных из `public/data/tajik-registry.json` через кэшируемый лоадер с состоянием `loading/error/retry`.
- **Ложные срабатывания проверки имени**: `normalizeNameQuery` схлопывает `о→а`, `е→и`, `я→а`, `ю→у`, поэтому разные имена считаются «совпадением», а `isPermitted` выставляется по нечёткому совпадению. Переписываем: строгое совпадение = «разрешено», нечёткое = «похоже, проверьте» (отдельный статус `likely`), плюс расстояние Левенштейна для подсказок «возможно, вы имели в виду».
- Поиск фильтрует 3 461 запись на каждое нажатие клавиши — добавляем дебаунс 200 мс + предпосчитанный поисковый индекс (одна нормализованная строка на запись).
- `counts`/`alphabetStats` считаются от полного массива при каждом изменении набора — выносим в мемо-селекторы модуля.
- Клик по вкладке «Генератор»/«Аудио» не меняет `activeTab`, из-за чего активная подсветка «залипает» на предыдущей вкладке — фиксим.
- `navigator.clipboard.writeText` без обработки отказа — добавляем `try/catch` + fallback и тост об ошибке.
- Кнопка «Хониш» озвучивает таджикское имя голосом `ru-RU` — подставляем язык из настроек аудиоплеера.
- CSV-экспорт не экранирует переводы строк в `meaning` — чиним экранирование; добавляем экспорт JSON.
- Рендер: `React.memo` для карточки имени, `useCallback` для обработчиков, `content-visibility` для сетки.

## 3. Связи и API

- Внутренние связи, которые доделываем: карточка имени → `/numerology`, `/signature`, `/dna`, `/tafsir`, `/compare`, `/certificate` с пробросом имени; связь `matched_child_name_id` → карточка общего каталога (сейчас заполнена лишь у 250 имён — досопоставим программно по нормализованному имени + полу, без AI).
- Избранное (`useFavorites`) — привести к единому формату id, чтобы имена реестра корректно отображались на `/favorites`.
- Подготовка к будущей интеграции с БД: единый слой `src/lib/api/tajikRegistryApi.ts` с типизированными функциями (`fetchRegistry`, `fetchNameBySlug`, `searchRegistry`, `checkName`, `fetchEnrichment`), который сейчас читает статический JSON, а позже переключается на Supabase одним флагом.
- Обогащение оставшихся 2 194 имён: таблица `tajik_registry_enrichment` (name_key, meaning, history, origin, source, model, created_at) + GRANT + RLS (публичное чтение, запись только service_role) и edge-функция `enrich-tajik` (Gemini, батчами, с квотами) — по образцу существующего `enrich-names`. Страница подмешивает эти значения поверх статики.

## 4. Дизайн и UX

- Скелетоны сетки/таблицы на время загрузки JSON, экран ошибки с «Повторить», пустое состояние с подсказками.
- Липкая панель фильтров на мобильном, счётчик активных фильтров и кнопка «Сбросить».
- Алфавитная лента: текущая буква подсвечивается при скролле, буквы без имён приглушены.
- Карточка: бейджи «Расмӣ», «Бо маъно», аккуратная типографика таджикской кириллицы, отдельная строка латиницы, быстрые действия в один ряд (копировать, озвучить, избранное, выписка).
- Тёмная тема и контраст изумрудной палитры приводятся к семантическим токенам (без хардкода цветов там, где это возможно).
- Мобильная адаптация под 592px (текущий вьюпорт): вкладки-чипы, 1 колонка, плеер не перекрывает пагинацию.

## 5. Новые функции

- **Пермалинки и шаринг**: `?tab=&q=&gender=&letter=&page=` + `/tajik-names?name=<slug>` открывает детальный диалог; кнопка «Поделиться».
- **Умные фильтры**: длина имени, количество слогов, «начинается/заканчивается на», «только с готовым значением», «редкие буквы» (Ғ, Қ, Ҷ, Ӯ, Ӣ).
- **Быстрые кнопки-пресеты**: «Кӯтоҳтарин» (короткие), «Нодир» (редкие), «Барои дугоникҳо» (пары брат/сестра с одним корнем), «Мувофиқ ба фамилия» — подбор по отчеству/фамилии.
- **Проверка ФИО целиком**: имя + отчество (-зода/-иён/-ӣ) + фамилия с оценкой соответствия правилам записи и предупреждениями (русифицированные окончания -ов/-ев).
- **Сравнение до 3 имён реестра** и «Топ по буквам» в инфографике (диаграмма, доля мужских/женских, самые частые начала/окончания).
- **Оффлайн-кэш** реестра в IndexedDB/localStorage с версией, чтобы повторные заходы были мгновенными.
- **SEO**: `<SEO>` с title/description, JSON-LD `Dataset` + `FAQPage` для вкладки законодательства, ссылка на официальный PDF Кумитаи забон.

## Этапы

1. **Фундамент**: вынос данных в `public/data/`, `tajikRegistryApi.ts`, lazy-маршрут, скелетоны/ошибки, кэш. Тесты не ломаем (обновим на асинхронный загрузчик).
2. **Логика проверки**: новый `checkTajikNameLegality` со статусами `permitted | likely | not_found`, Левенштейн, проверка ФИО; расширяем `src/test/tajikRegistry.test.ts`.
3. **Каталог и UX**: URL-состояние, умные фильтры, пресеты, мемоизация, редизайн карточки/таблицы, мобильная адаптация.
4. **Связи**: досопоставление с общим каталогом, переходы в инструменты, избранное, шаринг, SEO/JSON-LD.
5. **Данные**: миграция `tajik_registry_enrichment` + edge-функция `enrich-tajik`, подмешивание значений в UI, индикатор покрытия.
6. **Инфографика и полировка**: графики, топы, экспорт CSV/JSON, финальный прогон тестов и сборки.
