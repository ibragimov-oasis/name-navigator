# ИИ-агенты на Gemini Decision 1 и Flash Lite

## Цель
Добавить на сайт пять быстрых ИИ-агентов: законность по реестру РТ, оценка имени по сунне, созвучие в Мастере, автопополнение на Flash Lite и (как эксперимент) колыбельная имени. Ничего существующего не удаляем: старые проверки остаются как запасной вариант.

## Шаг 0. Проверка моделей (первым делом)
- Отправить тестовые запросы с текущим `GEMINI_API_KEY` к `gemini-decision-1`, `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`.
- Ключ раньше получал 403 — если ошибка останется, попросить пользователя обновить ключ в Secrets.
- Если отдельного Decisions-эндпоинта нет или он отвечает в другом формате, шлюз использует обычный `generateContent` со строгим JSON-ответом (вероятности по вариантам). Интерфейс для сайта при этом не меняется.

## Шаг 1. Шлюз `gemini-decisions` (новая функция на сервере)
- Режимы: `yes_no`, `choice`, `rubric`; вход проверяется через Zod.
- Цепочка моделей: decision-1 → 3.5-flash-lite → 3.1-flash-lite.
- Ответ: `{ decision, confidence, options[{label, p}], reason, model }`.
- Кэш одинаковых запросов в браузере на 7 дней; ограничение частоты запросов на клиенте.

## Шаг 2. Клиент `src/lib/ai/geminiDecisions.ts`
- `evaluateLegalityDecision(fio)`, `evaluateAdabScore(name)`, `evaluateHarmonyScore(family)` — строгие типы, без `any`.
- Сначала работает локальная логика (реестр, `calculateHarmony`), ИИ дополняет её. Если ИИ недоступен, показываем локальный результат.

## Шаг 3. Агент законности РТ
- `TajikNames.tsx` (вкладка проверки) и `TajikFioChecker.tsx`: бейдж «Решение ИИ» с одним из 4 вариантов, процентом уверенности и обоснованием, рядом с текущим результатом по реестру.
- Точное совпадение в реестре всегда важнее ответа ИИ.

## Шаг 4. Агент сунны и адаба
- Новый компонент `AdabBadge` (шкала 0–4: Харам / Макрух / Сомнительное / Мубах / Мустахабб) в `WizardNameDetailDialog`, `TajikNameDetailDialog` и `NameCard` (по нажатию, без автозапросов).
- Пометка «оценка ИИ, не фетва».

## Шаг 5. Агент созвучия в Мастере
- `NameWizard.tsx`: кнопка «ИИ-проверка созвучия» для шорт-листа (топ-5): фонетика стыков, ритм с братьями и сёстрами, звучание во взрослом возрасте. Итог объединяется с локальной оценкой.

## Шаг 6. Автопополнение на Flash Lite
- `enrich-names`: порядок моделей 3.5-flash-lite → 3.1-flash-lite → текущий Lovable AI Gateway → Pollinations.
- Учёт дневного лимита по каждой модели (500 в сутки) через существующую `llm_quota_usage`.

## Шаг 7. Колыбельная имени (эксперимент)
- Проверить доступ к Lyria RealTime. Если доступ есть — кнопка «Колыбельная» в карточке имени (ритм по слогам). Если нет — блок остаётся помеченным «Скоро» и не ломает сайт.
