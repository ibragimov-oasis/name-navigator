
## Что уже есть у нас (сильные стороны)

База имён, фильтры, фавориты, профили, совместимость, Nasab, DNA, нумерология, тафсир, подпись, дуа, исторические личности, псевдоним, персонаж, питомцы, календарь, баттл, мастер выбора, AI-чат Gemini.

По сути мы уже сильнее, чем TheBump и BabyCenter по глубине ислама и инструментов. Но у топ-сайтов есть **6 функций**, которых у нас нет или они слабые. Закрываем именно их.

## Пробелы и куда их добавить

### 1. Baby Name DNA Quiz (Nameberry, оценка 9.6) — **главный пробел**
Сейчас `/dna` анализирует **уже выбранное имя**. У Nameberry это **тест на стиль родителя**: 10–12 вопросов о вкусах → выдаёт «тип» (классика, природа, экзотика, духовное, винтаж и т.п.) → список из 30–50 подходящих имён.

**Куда добавить:** новый раздел `/style-quiz` (или вкладка внутри `/dna`).
**Как:** локальная логика — 10 вопросов с вариантами, каждый вариант = веса по 8 «стилям». Сумма даёт топ-2 стиля. Имена тегируются стилями в существующих батчах (добавить поле `style?: string[]`). Никакого AI не нужно — чистая математика, мгновенно.

### 2. Last-name compatibility / Full-name preview (Baiby 9.2, TheBump 8.7) — **второй главный**
У нас есть `nameHarmony.ts`, но он не используется как «введи фамилию и отчество — получи список совместимых имён».

**Куда добавить:** на `/children` сверху панель «Фамилия + отчество», на `/wizard` шаг «Фамилия». На карточке имени бейдж «✓ хорошо с Ивановым» + проверки:
- ритм слогов (есть в `nameHarmony`)
- инициалы (BAD/ХАМ/УЕБ — стоп-список)
- созвучие окончаний
- «как зовут на площадке» (короткая форма)

Всё локально, без токенов.

### 3. Tinder-свайп для пары (TheBump, BabyCenter, Babyname app)
У нас есть `/battle` (1-на-1), но нет **парного режима**: двое родителей независимо свайпают, потом видят совпадения.

**Куда добавить:** в `/battle` режим «Вдвоём» — генерится короткий код, оба свайпают на своих устройствах (хранение в Supabase таблице `swipe_sessions`), экран «Совпадения». Локально без аккаунта.

### 4. Реальная статистика популярности по регионам (zags.nalog.gov.ru 8.8)
У нас `/stats` есть, но без среза по регионам/годам. Российский ЗАГС силён именно этим.

**Куда добавить:** на `/stats` фильтр «регион РФ» + «год 2015–2025». Данные — статический JSON `src/data/regionPopularity.ts` (топ-50 имён по 10 крупным регионам, ручной парсинг с открытых данных Росстата/ЗАГС, одноразовая загрузка).

### 5. Породный/характерный фильтр для питомцев (AKC 8.4)
`/pets` сейчас — общий список. Нет фильтра по породе/размеру/характеру.

**Куда добавить:** на `/pets` фильтры: вид (собака/кошка/др.), порода (20 популярных), размер, характер (игривый/спокойный/охотничий). Проверка «как звучит команда» — произнести вслух / TTS-кнопка + автопроверка длины (1–2 слога лучше).

### 6. Брендовый/никнейм генератор для соцсетей (Namelix 8.6)
`/people/pseudonym` есть, но без проверки доменов/занятости в соцсетях и без коротких брендовых форм.

**Куда добавить:** в `/people/pseudonym` блок «Никнейм для соцсетей»:
- генерация коротких форм (5–10 символов) из выбранного имени
- проверка занятости через публичные API (github.com/USER → 200/404, ничего платного)
- кнопка «Сгенерировать через Gemini» с системным промптом «брендовое короткое имя в духе X»

## Что НЕ добавляем (уже сильнее конкурентов)

- Глубина значений / тренды / списки — у Nameberry лучше базы, но у нас уже есть исламский раздел, которого нет ни у кого
- AI-помощник — у нас уже Gemini-чат с активным профилем (Baiby проще)
- Fantasy/RPG-ники — узкая ниша, не наш фокус (исламский)

## Порядок реализации

Сделаем за 3 захода (каждый ~автономный):

1. **Заход 1 (самое полезное):** Style Quiz + Family Name Bar + Initials Checker.
2. **Заход 2:** региональная статистика + породные фильтры питомцев.
3. **Заход 3:** парный свайп + никнейм-генератор.

Если согласен — стартую с **захода 1**. Или скажи, что делать в первую очередь.
